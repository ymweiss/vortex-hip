# HIP Runtime Structure

This document explains the organization of the HIP runtime code in the vortex_hip repository.

## Overview

The HIP runtime is organized into two clear directories:
- **host/** - Headers for host-side code (linking with libhip_vortex.so)
- **device/** - Headers for device-side code (Polygeist compilation)

```
runtime/
├── host/                         # Host-side headers
│   ├── hip_vortex_runtime.h      # Main HIP API header
│   └── hip/
│       └── hip_runtime.h         # Standard HIP include path
├── device/                       # Device-side headers
│   ├── hip_runtime.h             # Device header for Polygeist
│   └── advanced/                 # Advanced features (not currently used)
│       └── hip_vortex_device.h   # Atomics, shuffles, intrinsics
├── hip_vortex_runtime/
│   └── src/                      # Implementation files
│       ├── hip_device.cpp
│       ├── hip_memory.cpp
│       ├── hip_kernel.cpp
│       └── hip_error.cpp
└── build/                        # Build output (libhip_vortex.so)
```

## Host Headers (runtime/host/)

Used for compiling host applications that use the HIP API.

### hip_vortex_runtime.h

The main header providing:
- HIP error codes (`hipError_t` enum)
- HIP types (`dim3`, `hipMemcpyKind`, `hipDeviceProp_t`)
- Memory management (`hipMalloc`, `hipFree`, `hipMemcpy`)
- Device management (`hipInit`, `hipSetDevice`, `hipDeviceSynchronize`)
- Kernel launch (`vortexLaunchKernel`, `hipLaunchKernelGGL` macro)
- Vortex types (`VortexKernelArgMeta`, `VortexKernelArgs`)

### hip/hip_runtime.h

Standard HIP include path wrapper - simply includes `../hip_vortex_runtime.h`.

Usage:
```cpp
#include <hip/hip_runtime.h>  // Resolves to hip_vortex_runtime.h
```

## Device Headers (runtime/device/)

Used for device code compilation with Polygeist.

### hip_runtime.h

Minimal header for Polygeist device compilation:
- `__clang_cuda_builtin_vars.h` for threadIdx, blockIdx, etc.
- `__global__`, `__device__`, `__shared__` attribute macros
- `dim3` struct for kernel launch syntax
- `cudaConfigureCall`/`hipConfigureCall` declarations
- Device printf declaration

### advanced/hip_vortex_device.h

Advanced device features (not currently used by Polygeist pipeline):
- Atomic operations (atomicAdd, atomicCAS, atomicMin, etc.)
- Warp voting (__all, __any, __ballot)
- Warp shuffles (__shfl, __shfl_up, __shfl_down, __shfl_xor)
- Math intrinsics (__fsqrt_rn, __fmaf_rn, etc.)
- Vortex-specific extensions (getWarpId, getCoreId, etc.)

## Include Paths

### Host Code (g++)
```bash
g++ -I runtime/host ...
```

### Device Code (Polygeist/cgeist)
```bash
cgeist -I runtime/device ...
```

## Key Types and Functions

### VortexKernelArgs (kernel argument header)
```cpp
typedef struct VortexKernelArgs {
    uint32_t grid_dim[3];   // Offset 0, 12 bytes
    uint32_t block_dim[3];  // Offset 12, 12 bytes
    // User arguments follow at offset 24
} VortexKernelArgs;
```

### VortexKernelArgMeta (argument descriptor)
```cpp
typedef struct VortexKernelArgMeta {
    uint32_t offset;      // Offset in host args struct
    uint32_t size;        // Size in bytes
    uint32_t is_pointer;  // 1 for device pointers
} VortexKernelArgMeta;
```

### vortexLaunchKernel (kernel launch)
```cpp
hipError_t vortexLaunchKernel(
    const char* kernel_name,
    dim3 gridDim,
    dim3 blockDim,
    const void* args,           // Pointer to packed args struct
    size_t args_size,
    const VortexKernelArgMeta* metadata,
    size_t num_args
);
```

This function:
1. Loads the kernel binary (`.vxbin` file)
2. Builds the device args buffer (header + user args)
3. Converts 64-bit host buffer handles to 32-bit device addresses
4. Uploads args to device memory
5. Starts kernel execution

## Build System

### CMakeLists.txt
```cmake
target_include_directories(vortex_hip
    PUBLIC
        $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/host>
        $<INSTALL_INTERFACE:include>
    ...
)
```

### Build Commands
```bash
cd runtime/build
cmake .. -DVORTEX_ROOT=../vortex
make
```

Output: `runtime/build/libhip_vortex.so`

## Dependencies

```
libhip_vortex.so
    └── libvortex.so (from vortex/build/runtime/)
        └── vx_dev_open, vx_mem_alloc, vx_start, etc.
```
